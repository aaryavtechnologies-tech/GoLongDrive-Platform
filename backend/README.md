# Long Distance Taxi Booking Platform - Backend

This is the fully scalable, production-ready backend for the Long Distance Taxi Booking Platform, built with Node.js, Express, MongoDB, and Socket.io.

## Key Features

- **Authentication**: JWT-based auth for Customers, Drivers, and Admins.
- **Role-Based Access Control (RBAC)**: Highly granular Admin permissions.
- **Booking Engine**: Handles One Way, Round Trip, Airport Drop/Pickup, and Custom Tours.
- **Real-Time Notifications**: Socket.io integration.
- **Financial Module**: Invoicing, driver earnings, platform fees, and coupon management.
- **Review System**: Rate and review completed trips.
- **Admin Dashboard**: Aggregated analytics and CMS management.
- **Security**: Helmet, XSS-Clean, Rate-Limiting, NoSQL Injection Protection.
- **Background Jobs**: Node-Cron for scheduled maintenance.
- **Monitoring**: Winston daily rotating logs & health endpoints.

## Environment Setup

Create a `.env` file in the `backend/` directory:

```env
PORT=5000
NODE_ENV=development
CLIENT_URL=http://localhost:3000

MONGO_URI=mongodb://localhost:27017/taxi-booking
JWT_SECRET=your_super_secret_key
JWT_EXPIRE=30d

SMTP_HOST=smtp.mailtrap.io
SMTP_PORT=2525
SMTP_USER=your_smtp_user
SMTP_PASS=your_smtp_pass
FROM_EMAIL=noreply@taxibooking.com

RESEND_API_KEY=your_resend_api_key
```

## Installation & Execution

1. **Install Dependencies**:
   ```bash
   npm install
   ```
2. **Run in Development**:
   ```bash
   npm run dev
   ```
3. **Run in Production (PM2)**:
   ```bash
   npm install pm2 -g
   pm2 start ecosystem.config.js --env production
   ```

## Documentation

Once the server is running, you can view the complete interactive API documentation via Swagger UI at:
- `http://localhost:5000/api-docs`

## Folder Structure

- `src/controllers/`: Route handlers.
- `src/models/`: Mongoose schemas.
- `src/routes/`: Express route definitions.
- `src/services/`: Reusable business logic (Email, Notifications, Analytics).
- `src/middleware/`: Auth, Roles, Error catching, Validation.
- `src/cron/`: Scheduled tasks.
- `src/config/`: DB and Socket setups.
- `src/utils/`: Helpers and customized Winston logger.
- `logs/`: Autogenerated structured daily logs.
