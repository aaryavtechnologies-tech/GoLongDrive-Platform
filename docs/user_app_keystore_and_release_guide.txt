4. COMMANDS TO BUILD FINAL RELEASE APK & APP BUNDLE
--------------------------------------------------------------------------------
Open Terminal on your Mac and navigate to the user-app directory:

    cd /Users/wefix/Documents/chirag-projects/GoLongDrive-Platform/user-app

Clean previous builds (recommended before release):
    flutter clean
    flutter pub get

A) Build Release APK (For installing directly on physical Android phones for testing):
    flutter build apk --release

    Output APK location:
    build/app/outputs/flutter-apk/app-release.apk

    To install directly on your USB-connected Android phone:
    flutter install --release
    - OR -
    adb install -r build/app/outputs/flutter-apk/app-release.apk

B) Build Android App Bundle (.aab) (REQUIRED for Google Play Console Submission):
    flutter build appbundle --release

    Output AAB location:
    build/app/outputs/bundle/release/app-release.aab
